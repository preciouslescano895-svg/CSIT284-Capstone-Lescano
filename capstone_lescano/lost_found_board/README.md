## Project Description
Lost & Found Board is a Flutter application
designed to help students find lost belongings
and report found items.
Users can post lost or found items with image
URLs, descriptions, and contact information.
Other users can browse items and mark them
as claimed.
The application does not include messaging
or chat functionality.
## Features
- Lost and Found Feed
- Post Lost or Found Items
- Image URL Support
- Item Description
- Contact Information
- Mark as Claimed
- Filter Lost and Found Items
- Navigation Between Two Screens
- 10 Dummy Items

## Current Limitations
This is a classroom prototype.
New items and claimed statuses are temporarily
stored while the application is running.
Restarting the application restores the
original 10 sample items.
